# MoreUI

## 项目介绍

MoreUI（Multiple oreUI）是一款允许您在同一UI界面上快速创建多个表单的便携库。

MoreUI实际上是国际版DDUI（Data-Driven UI）的升级版，感兴趣者可以查看微软文档[DDUI](https://learn.microsoft.com/en-us/minecraft/creator/documents/scripting/intro-to-ddui?view=minecraft-bedrock-stable)

您可以在服务端动态地创建和更新表单，并实时获取用户输入。
